# Server Patch Desk

Operate mode. Persian RTL operations desk with LTR server addresses, commands and package evidence. Warm white paper, dark ink, restrained forest green for actions, amber for pending verification, red for failure. Desktop uses a server register beside an inspection detail pane; mobile stacks the same controls. No fabricated servers or success counters. Native form controls, clear focus rings, real empty and loading states. Decisions are provisional implementation choices while the user's optional preferences are pending.
