ابزار فقط همین پورت‌های مشخص‌شده را امتحان می‌کند و پورت موفق در اولویت اتصال بعدی می‌ماند.

رمزهای سرورها متفاوت‌اند؟

لیست IP را وارد کنید و دکمه زیر را بزنید. برای هر سرور می‌توانید رمز جدا بنویسید؛ فیلد خالی از رمزهای مشترک استفاده می‌کند.

با شروع، اگر آپدیت لازم باشد بسته‌های PHP و سرویس‌های Compose قابل‌شناسایی به‌روزرسانی و سرویس مربوط restart می‌شود. image سفارشی یا tag ثابت قدیمی ممکن است نیاز به اصلاح داشته باشد. پیش از شروع، backup داشته باشید. اثر انگشت خودکار پذیرفته و رمز sudo از رمز ورود موفق گرفته می‌شود.

مشخصات اتصال

هر دو کاربر با رمزهای واردشده امتحان می‌شوند؛ ورود موفق برای اتصال بعدی در اولویت می‌ماند. رمز sudo همان رمز ورود موفق است. اثر انگشت SSH خودکار پذیرفته می‌شود. حداکثر ۶ تلاش ناموفق ممکن است حساب را قفل کند؛ رمزها فقط در حافظه‌اند.
